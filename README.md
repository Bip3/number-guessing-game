# The Advanced Number Guessing Game

Welcome to the Advanced Number Guessing Game!
To run this script, clone the repository, and run python3 guess.py from root
The Game will prompt the user to select a game mode and a difficulty

# Classic Mode
Classic Mode gives the user a variable number of guesses (depending on difficulty) to
guess a random number generated by the script. The user input MUST be an integer (I've made sure of it)
If the user doesn't guess the correct number in the allotted tries, the game will end
On each incorrect guess, the computer will till the user if the true number is higher or lower than the current guess

# Time Trial Mode
Time trial mode gives the user a variable number of guesses (depending on difficulty) to
guess a random number generated by the script. The user input MUST be an integer (dont you dare test me)
If the user doesn't guess the correct number in the allotted tries by the designated time (default 60 seconds)
the game will end. On each incorrect guess, the computer will tell the user if the true number is higher or lower
